# wheremycv

เว็บแอป (LINE LIFF) ช่วยจำว่าส่ง CV/Resume ไปที่ไหน เมื่อไหร่ ใครตอบกลับแล้วบ้าง มีนัดสัมภาษณ์วันไหน พร้อมแจ้งเตือนผ่าน LINE

เป็นแบบ **self-host**: โคลน repo นี้ไป ใส่ key ของตัวเอง แล้ว deploy ขึ้น Cloudflare ของตัวเอง

> 🚧 กำลังพัฒนา ตอนนี้ยังไม่มีโค้ด วิธีติดตั้งจะเพิ่มเมื่อโค้ดพร้อม
